Get an email when someone needs you

Turn on email alerts for "Ask Kale to let me in" requests and reported posts. One-time setup:

  1. Resend → API Keys → Create API key. Name it site alerts, permission Sending access, domain kaleerson.com. Copy it.
  2. Supabase → your project → Edge Functions → Secrets → add RESEND_API_KEY with the key as the value. Don't paste it anywhere else.
  3. Reload this page. This box disappears once it's working.

People

Everyone who has signed up. If someone's email blocks the sign-in message (school emails often do):

  • Give access makes a personal link that signs them in every time, on any device. Send it to them; they can bookmark it. Turn off stops it. Making a new one turns off the old one.
  • One-time link works once and expires in about an hour.
  • Once they're in, they can also set a password on the Join page and sign in with email + password.
  • Style sets the color of someone's name and up to 5 tags (like Debate or Mod). Everyone sees them on the forum, Study and leaderboards. Usernames can't be changed by members; you can fix one in Supabase if you have to.
