Changes made to the game
------------------------
None. Every file is unmodified upstream; the only addition is this ATTRIBUTION.txt.
index.html references only files in this folder (index.js, index.png, index.icon.png,
index.apple-touch-icon.png); index.js loads index.wasm, index.pck and the two audio worklets from
the same folder. There are no CDN, font, analytics or other third-party requests.
The export sets GODOT_THREADS_ENABLED = false and ships no index.worker.js, so it does not need
SharedArrayBuffer or Cross-Origin-Opener/Embedder-Policy headers (index.js only mentions
SharedArrayBuffer inside the threads-only feature check, which is skipped). Requires WebGL 2.
