Known external request (left in on purpose)
-------------------------------------------
build/sketchbook.min.js appends three <link rel="stylesheet"> tags to the page head at start-up
that point at Google Fonts (fonts.googleapis.com: "Alfa Slab One", "Solway", "Cutive Mono"; the
returned stylesheet then references fonts.gstatic.com). They only style the in-game text panel.
The minified bundle was deliberately not edited. If those requests are blocked or fail (for
example on a filtered school network) the panel falls back to the browser's default fonts and the
game itself is unaffected - this was verified with the font hosts blocked. Everything else
(scripts, models, textures) is loaded from this folder on kaleerson.com.

- kaleerson.com: added a Content-Security-Policy meta tag to index.html so the page only loads from its own origin (the bundle appends Google Fonts links at start-up; they are now blocked and the panel uses fallback fonts). No other change.
