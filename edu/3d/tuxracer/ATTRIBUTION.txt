Build (Node v22.22.0, npm 10.9.4; done in a scratch clone outside this repository)
-----------------------------------------------------------------------------------
  git clone --depth 1 https://github.com/ebbejan/tux-racer-js      # HEAD = 8d2a6aea698db0a199ca39f3f4d754a134105bc8
  npm install
  npm run build          # = tsc && vite build   (vite.config.js sets base './', so all paths are relative)  -> dist/
  cp -r dist/.   <this folder>/        (index.html + assets/: one JS bundle, one CSS file, webp/ogg game data)
  cp LICENSE     <this folder>/LICENSE

Every change compared with upstream
-----------------------------------
  None to the code, build output or assets. The only additions are this ATTRIBUTION.txt and the copied
  LICENSE. The production Vite build emits no source maps (none to delete). The game references no
  external hosts; a headless run of this copy confirmed that only same-origin requests are made.
